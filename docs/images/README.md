# User manual screenshots

This directory contains the twelve screenshots embedded in the
[User Manual](../UserManual.md).

Keep the existing filenames when replacing a screenshot. Image links in the
manual use `images/<filename>.png`, relative to the manual itself, not
`docs/images/<filename>.png`.

Capture the application with the default dark theme and use demonstration data.
Before publication, review visible filesystem paths: screenshots 02 and 11
currently show the local project path. Replace those captures if that path
should not be public. The screenshots have not been altered during the manual
review.
