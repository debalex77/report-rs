# Changelog

All notable changes to this project are documented here.

## [0.1.0-alpha.1] - 2026-09-03

First public alpha release.

### Added

- Visual report Designer with editing, history, layouts and contextual actions.
- Interactive Preview with progress stages, timing information and PDF export.
- SQLite data sources, parameters, query filters and sorting.
- Text formatting, report functions and numeric aggregate functions.
- Report, page, data, Group Header and Group Footer bands.
- Nested groups, repeated group headers and per-group subtotals.
- Automatic table generation with row numbers and multiple grouping levels.
- PNG, JPEG and SVG image decoding, including images stored as database BLOBs.
- Example reports and SQLite database.
- GitHub Actions continuous integration and release packaging.
