# Standard license texts accompanying published declarations

These are unmodified SPDX license-list-data v3.26.0 texts, not recovered
package-specific license files. Source URLs and hashes are in `index.json`.
Placeholder copyright fields in the SPDX MIT template are not assertions
about any package's authors, dates or rights holders.

For the exact package versions in `reviewed-declarations.json`, Cargo's
published manifest declares the indicated license. The manifest SHA-256 is
pinned, so changed declarations require review. Where upstream offers a choice,
the selected option is recorded explicitly; historical `/` expressions here
indicate alternatives. No additional license is granted by this file.

For these packages the collector includes the original manifest, author metadata
(not represented as a copyright ownership statement), existing notices and
the complete cached crate source. This preserves the supplied attribution and
source headers rather than synthesizing copyright statements. Sources for all
MPL-2.0 packages are included as well.

This resolves collection of declared license texts, not a legal certification
of ownership or compliance. The two MIT-only packages convert_case 0.4.0 and
kuchiki 0.8.1 do not ship a package-specific copyright/license file: their
published MIT declaration and author metadata are retained, but are not claimed
to be a recovered original copyright notice. Native/system components and
embedded third-party material may carry additional obligations.
