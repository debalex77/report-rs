# Supplemental dependency license evidence

These files were retrieved from the packages' upstream repositories at the
published Cargo VCS revisions. `index.json` records their URLs and SHA-256
checksums. The original license texts are not rewritten or relicensed.

Some upstream files are license pointers rather than complete licenses. In
particular, the four GPU allocation/descriptor COPYING files are supplemented
by standard Apache-2.0 terms under the declaration-based method in
`../standard/README.md`. Empty file lists record unsuccessful upstream retrievals,
not the absence of a declared license. See `docs/DEVELOPMENT.md` for scope.

The release collector verifies hashes and matching license expressions and
revisions before including this evidence. The zune crates use the declared Zlib
option, whose complete text is included alongside the upstream copyright notice.

This evidence collection is not a legal determination of every dependency's
compliance. It supplements the licenses, notices and MPL source archives
collected directly from the locked Cargo package sources.
